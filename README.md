# Environment · C1 — тренажёр лексики

Две части: 20 заданий с выбором слова в пропуск и 15 слов на перевод по контексту.
Плюс отдельный модуль «Карточки» — интервальное повторение тех же слов, как в Anki.
У каждого ученика своя ссылка, учитель видит результаты и ответы.

## Запуск

```bash
pip install -r requirements.txt
python app.py
```

- Тренажёр: http://127.0.0.1:5050/s/<токен ученика>
- Карточки: http://127.0.0.1:5050/s/<токен ученика>/cards
- Учитель: http://127.0.0.1:5050/admin — ключ в `data/admin_key.txt` (и в консоли при запуске)

## Как пользоваться

1. В `/admin` вставьте список имён (по одному на строку) → «Добавить».
2. «Скопировать все ссылки» — получите строки «Имя — ссылка», рассылаете ученикам.
3. Результаты: лучший / последний процент, кто проходит прямо сейчас, трудные слова класса,
   по клику на имя — все ответы ученика.

## Карточки (интервальное повторение)

- Алгоритм SM-2, как в Anki: оценки «Снова / Трудно / Хорошо / Легко», на кнопках видно, когда слово вернётся.
  Новое слово: шаги 1 мин → 10 мин → 1 день; дальше интервал растёт (2 → 5 → 13 дней → месяц…).
  Забыл — слово уходит на переучивание, интервал сокращается.
- Персонализация: новые карточки идут в порядке «ошибся в тесте» → «не отвечал» → «ответил верно».
  До 10 новых в день (кнопка «Ещё 5 новых»), повторения — сколько назначено.
- Ученик видит колоду (не начато / изучаю / запоминаю / выучено надолго), серию дней и прогноз на неделю.
- Учитель видит в таблице, сколько слов изучено и повторено сегодня, а в карточке ученика — его самые трудные слова.
- Настройки — константы в начале `srs.py`.

## Где что

- `srs.py` — расписание повторений и очередь карточек.
- `exercises.py` — тексты заданий. Для перевода `accept` — основы слов, по которым засчитывается ответ.
- `data/lexis.db` — SQLite с учениками и ответами (в git не попадает).
- Настройки через переменные окружения: `PORT`, `HOST` (для доступа из сети — `0.0.0.0`), `ADMIN_KEY`, `SECRET_KEY`.
